Responsive CSS Cheat Sheet

Filters

Used to change the appearance of images.

filter: grayscale(100%);

Media Queries

Used to apply CSS based on screen size.

@media (max-width: 700px)

Responsive Design

Makes websites adapt to different devices.

width: 100%;

Typography

Controls text size for different screens.

font-size: clamp(1rem, 2vw, 2rem);
